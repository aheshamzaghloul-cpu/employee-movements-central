# v50.0 — إعادة بناء التصميم الاحترافي

هذه النسخة تعيد بناء طبقة العرض بالكامل من ملف تصميم مستقل `design50.css` بدل الاعتماد البصري على طبقة التصميم السابقة.

## مبادئ العرض
- كل صفحة تبدأ بهوية واضحة وعنوان ووصف.
- كل وظيفة رئيسية داخل قسم مستقل بحدود ومسافات واضحة.
- عناوين المربعات داخل كتلة زرقاء موحدة باللون `#214f8e`.
- النماذج والفلاتر والجداول منفصلة بصريًا.
- الصفحة الرئيسية مقسمة إلى: الترحيب، البحث، المؤشرات، حالة الموظفين، المدخل الأول، الإجراءات السريعة، نبض التشغيل، المساعد والنتائج.
- الإدارة مقسمة إلى مناطق مستقلة: الإحصاءات، مهام الإدارة، الحسابات والأدوار، المدخل الأول، الهيكل، الاستيراد، التدقيق.
- دور `المدخل الأول` يبقى أهلية تنظيمية وليس حساب دخول.
- دعم RTL والاستجابة للشاشات الصغيرة.
