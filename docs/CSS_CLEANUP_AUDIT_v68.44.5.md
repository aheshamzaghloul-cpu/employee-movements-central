# تدقيق تنظيف CSS — v68.44.5

## النطاق

تنظيف محافظ للتصريحات التي تتكرر خصائصها في قاعدة لاحقة للمحدد نفسه وفي سياق at-rule نفسه، مع التركيز على الإطار العام والتنقل والحقول والنماذج والجداول والبطاقات ومكونات مساحة العمل المشتركة.

## قواعد السلامة

1. لا يُنظَّف إلا المحدد المفرد المطابق حرفيًا بعد تطبيع المسافات، مع تطابق كامل لسياق `@media` و`@supports` و`@layer` وما شابه.
2. لا تُحذف أي خاصية مكررة داخل القاعدة نفسها؛ لأن ذلك قد يغيّر fallback أو تحسينًا تدريجيًا.
3. التصريح اللاحق يجب أن يملك أولوية `!important` مساوية أو أعلى من التصريح السابق.
4. أسماء custom properties (مثل `--Brand`) تُعامل على أنها حساسة لحالة الأحرف.
5. المحددات المجمعة، والكتل المحتوية على تعليقات أو أخطاء تحليل أو تصريحات غير قابلة للتحليل المحافظ، تُترك دون تغيير.
6. تُعدَّل التصريحات ذاتها فقط، مع الحفاظ على ترتيب القواعد والسياقات الشرطية.
