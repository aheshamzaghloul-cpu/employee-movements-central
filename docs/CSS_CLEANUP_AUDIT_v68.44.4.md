# تدقيق تنظيف CSS — v68.44.4

## نطاق الدفعة

ركزت الدفعة على قواعد الإطار العام والتنقل وحقول النطاق والجداول والبطاقات، مع التعامل مع تسجيل الدخول والرئيسية ضمن المكونات المشتركة. لم يُستخدم الحذف حسب اسم المحدد وحده.

## طريقة القرار الآمن

حُذفت قاعدة سابقة فقط إذا تحققت الشروط كلها:

1. تطابق النص الكامل للمحدد بعد تطبيع المسافات، لا مجرد وجود اسم عنصر أو صنف داخل مجموعة مختلفة.
2. تطابق سياق قواعد `@media` و`@supports` وما شابه.
3. كل خاصية في القاعدة السابقة موجودة في قاعدة لاحقة مطابقة، وتغطي الأولوية نفسها؛ إذا كانت السابقة `!important` فيجب أن تكون اللاحقة `!important` كذلك.
4. لا تحتوي القاعدة على تعليقات/أخطاء تحليل، ولا تكرر اسم الخاصية داخلها. هذا يحمي fallbacks والتصريحات المقصودة المتعددة.
