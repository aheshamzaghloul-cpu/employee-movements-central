# v49.14 — توحيد التقارير والمأموريات

تم توحيد الواجهة البصرية لوحدة **تقارير ومأموريات** ضمن Design System موحد.

## نطاق المرحلة
- مركز التقارير وبطاقات التقارير.
- إحصاءات الحركات.
- فلاتر تقارير الإجازات والانتدابات والأذونات.
- نتائج التقارير وتجميعها حسب الموظف.
- شاشة المأموريات وفلاترها وجدول النتائج.
- تعديل المأمورية وتاريخ الطباعة المؤقت للانتداب المفتوح.
- الحفاظ على قوالب الطباعة الرسمية مستقلة عن تصميم التطبيق.

## الاختبارات
- تحليل قوالب Jinja.
- Python compile.
- فحص توازن أقواس CSS.
