# v49.18 — توحيد المدخل الأول والإجراءات السريعة

- تم جمع كل ما يخص المدخل الأول في بطاقة واحدة داخل الصفحة الرئيسية.
- إزالة بطاقة KPI المنفصلة للمدخلين الأوائل حتى لا تتكرر المعلومة.
- بطاقة المدخل الأول تحتوي على الإضافة، عرض الأدوار، الفروع، تعديل الفروع، الاستبدال، وإزالة الدور.
- الإجراءات السريعة أصبحت بأيقونة SVG بجوار النص داخل كل إجراء، وليست أيقونات منفصلة عن العنوان.
- تم الحفاظ على منطق الصلاحيات والروابط الحالية.
