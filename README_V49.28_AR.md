# v49.28 — توحيد عناوين البطاقات في الرئيسية

تم توحيد لون العناوين والعناوين الفرعية التي تمثل محتوى داخل بطاقات الصفحة الرئيسية مع اللون الأزرق العميق المستخدم في مربع «مرحبًا بك» (#214f8e).

- عناوين البطاقات.
- عناوين البنود داخل البطاقات.
- عناوين حقول البحث.
- عناوين جدول حالة الموظفين.
- عناوين إحصاءات الحالات.
- عناوين الإجراءات السريعة.
- عناوين قائمة المدخل الأول.
- عناوين النشاط والتنبيهات.
- عناوين بيانات الموظف في نتائج البحث.

تم الإبقاء على الأرقام والحالات والأيقونات ذات الألوان الدلالية الخاصة بها، وعلى النصوص الوصفية باللون المحايد.
