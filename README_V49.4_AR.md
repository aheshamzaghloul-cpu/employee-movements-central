# v49.4 — توحيد الصفحات المتخصصة

هذه النسخة تكمل تنظيف Design System على مستوى الصفحات، مع الحفاظ على منطق التطبيق.

## ما تم
- توحيد صفحات الموظفين والحركات والتقارير والمأموريات والإدارة والحساب ضمن مكوّنات `ds-*` مشتركة.
- إدخال `ds-module-card` كحاوية موحدة للوحدات التشغيلية.
- توحيد حالات التركيز والتفاعل والبطاقات وروابط الإجراءات.
- استبدال الرموز النصية المتبقية في الواجهة بأيقونات SVG.
- الحفاظ على كلاسات سلوكية الصفحات عند الحاجة، مع نقل المظهر إلى طبقة Design System.

## التحقق
- Python compile: ناجح.
- Jinja parse: ناجح لجميع القوالب.
