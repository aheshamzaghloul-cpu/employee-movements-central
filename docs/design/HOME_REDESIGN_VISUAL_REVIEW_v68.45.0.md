# مراجعة مرئية للرئيسية — v68.45.0

## مقارنة الاتجاه المختار بالتنفيذ

تم تنفيذ تخطيط الصفحة الرئيسية اعتمادًا على الاتجاه الذي اختاره المستخدم: قاعدة بصرية فاتحة وبسيطة، سماوي مائل للأزرق، قوائم واضحة، واستخدام محدود للأزرق الداكن.

- رأس ترحيبي واضح مع تاريخ اليوم.
- أربعة اختصارات أساسية في شبكة واحدة على سطح المكتب، تتحول إلى عمودين على الهاتف.
- مساحة تنفيذ مستقلة تحت الاختصارات، تضم تسجيل حركة وبحث الموظف في بطاقتين منفصلتين.
- منطقة المتابعة (حالة الموظفين والمدخلون الأوائل) تبقى منفصلة عن إجراءات البدء.
- أدوات العمل في قسم مستقل أسفل المحتوى التشغيلي.

## ملاحظة منهجية

هذه معاينة محلية للقوالب الحقيقية المعدلة باستخدام بيانات اصطناعية؛ لم يُتصل بقاعدة بيانات، وأُزيل JavaScript من لقطة الشكل لأجل استقرار الصورة. لذلك لا يُستدل منها على نجاح الإرسال أو الحفظ أو سلوك قاعدة البيانات. هذه المرحلة تغير التكوين البصري للرئيسية، ولا تعني اكتمال إعادة تصميم كل صفحات التطبيق.
