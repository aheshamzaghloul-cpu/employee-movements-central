القوالب المعروضة في المعاينة الاصطناعية باستخدام CSS الحقيقي للمشروع: الحساب، الإشعارات، سجل التدقيق، القوائم الأساسية، الاستبدال الإداري، تعديل المستخدم، وحالة الخطأ. تستخدم المعاينة بيانات اختبار ثابتة ولا تنفّذ طلبات Flask أو تغييرات على قاعدة البيانات.

## حدود التحقق

- محاولة تشغيل مجموعة الاختبارات الكاملة `python -m pytest -q` توقفت عند تحميل `tests/conftest.py` لأن `Flask` غير مثبت في بيئة التنفيذ (`ModuleNotFoundError: No module named 'flask'`). لذلك لا يُدّعى نجاح اختبار تكامل حي للتطبيق.
- لم يتم الاتصال بقاعدة بيانات الإنتاج، ولم يتم النشر إلى GitHub أو Blitz.
- لم تتغير مقاصد مسارات العمل أو صلاحياتها أو أسماء حقول النماذج أو حقول CSRF أو مخطط قاعدة البيانات أو قوالب الطباعة الرسمية.
