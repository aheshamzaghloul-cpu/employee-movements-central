# استيراد Excel الذكي — v35.37

يمكن الآن استخدام ملف Excel الموجود لديك دون إعادة ترتيب الأعمدة لتطابق نموذج النظام.

## طريقة الاستخدام
1. افتح استيراد الفروع أو استيراد الموظفين.
2. اختر ملف Excel.
3. اضغط **قراءة الملف ومطابقة الأعمدة**.
4. سيقرأ النظام صف العناوين ويقترح المطابقة تلقائيًا.
5. راجع المطابقة وعدّل أي حقل عند الحاجة.
6. اضغط **تأكيد المطابقة واستيراد البيانات**.

ترتيب الأعمدة لا يهم، كما يدعم النظام مسميات عربية وإنجليزية شائعة للعناوين.

> ملاحظة: الاستيراد يدعم xlsx / xlsm / xltx. ملفات xls القديمة غير مدعومة بواسطة openpyxl الحالي.
