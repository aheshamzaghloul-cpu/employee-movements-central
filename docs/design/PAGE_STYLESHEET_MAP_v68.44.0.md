# خريطة التصميم وتغطية الصفحات — v68.44.0

## ترتيب أوراق الأنماط

- `static/css/app.css`: طبقة التوافق والبنية العامة القديمة.
- أوراق الصفحة المشروطة حسب المسار مثل `home.css` و`management.css` و`workspace-pages.css`.
- `static/css/design-system-cyan.css`: الرموز المشتركة للهوية السماوية والأزرق الداكن المحدود.
- `static/css/pages/admin-reports-assistant.css`: طبقة نهائية صغيرة ومحدودة النطاق للإدارة والتقارير والصلاحيات والمساعد، تشمل حالات التركيز وتجاوب الشاشات الصغيرة.

## تغطية هذه الدفعة

| الصفحة/المكون | القالب أو النطاق | التحسين |
|---|---|---|
| مركز الإدارة | `structure.html`, `.admin-workspace` | سطح بطل سماوي، لمسات كحلية محدودة، مؤشرات أكثر وضوحًا وحالات تحويم وتركيز. |
| المستخدمون وتعديل الحساب | `users.html`, `user_edit.html` | هرمية أقسام النموذج، خيارات الأدوار والنطاق، وحالات التركيز والتحديد. |
| التفويضات | `delegations.html`, `.delegation-workspace` | بطاقات السريان، التبويبات، النماذج وجدول السجل. |
| التقارير | `reports.html`, `reports_missions.html` | فهرس التقارير، بطاقات المؤشرات، المرشحات وإجراءات الوصول المباشر. |
| المأموريات | `mission_reports.html` | مرشحات متقدمة أوضح، رأس جدول، نتائج وإجراءات تتحمل المساحات الصغيرة. |
| مركز المدير | `manager_hub.html` | غلاف موحد للصفحة وإيقاع بطاقات وجداول متناسق. |
| سجل العمليات | `audit.html` | عنوان مع سياق وحجم السجل، وجدول داخل سطح واضح مع صفوف قابلة للقراءة. |
| المساعد | `assistant_dock.html`, `assistant.html`, `assistant_panel.html` | مشغّل أيقوني فقط باسم وصول، لوحة محادثة أخف، ورسائل وحقل إدخال متجاوبة. |

## ضمانات عدم تغيير السلوك

- بقيت قيم role وpermission والبوابات المعتمدة في القوالب كما هي.
- بقيت حقول نماذج المستخدمين والصلاحيات ونطاق المحافظات كما هي.
- بقيت مسارات التقارير والتصدير والطباعة وطلبات التعديل كما هي.
- بقي `POST /assistant` و`/assistant/confirm` وسياق المحادثة كما هو.
- بقيت قوالب المستندات الرسمية المستقلة للطباعة خارج أهداف تنسيقات هذه الدفعة.

## حدود التحقق

تم فحص الاختبارات التعاقدية وتحليل Jinja وCSS وPython وJavaScript. لم يكتمل تشغيل Flask/قاعدة بيانات حية أو معاينة متصفح فعلية؛ لذلك لا تُعد الخريطة إثباتًا بصريًا حيًا.
