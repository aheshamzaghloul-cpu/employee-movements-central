# v49.27 — تصحيح الصفحة الرئيسية وإعادة أهلية المدخل الأول

- إعادة ضبط تخطيط الصفحة الرئيسية وتوزيع بطاقات التشغيل.
- إصلاح شبكة الإجراءات السريعة لتظهر بعرض مريح.
- توحيد عناوين وبنود البطاقات على الأزرق العميق المستخدم في بطاقة الترحيب.
- منع قص عنوان بطاقة المدخل الأول.
- إعادة ظهور «المدخل الأول» في محرر أدوار الإدارة كأهلية تنظيمية.
- عند جمع «المدخل الأول» مع «مشرف محافظة» لا يتم إنشاء حساب دخول مستقل ولا تُفرض فروع تكليف من صفحة الحساب؛ التكليف يتم من الرئيسية.
