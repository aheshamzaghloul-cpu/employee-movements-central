# v49.29 — صناديق عناوين المربعات

- تم وضع عنوان كل مربع رئيسي داخل صندوق مستقل.
- لون صندوق العنوان هو الأزرق المتفق عليه `#214f8e` المستخدم في الهوية الرئيسية.
- نص العنوان أبيض ليوضح أنه عنوان الصندوق.
- تم الحفاظ على ألوان الأرقام والحالات والأيقونات الدلالية.
- لم يتم تغيير منطق الأدوار أو تكليف المدخل الأول.
