# تقرير المرحلة الأولى من إعادة تصميم النظام — v68.23.0

## حالة المرحلة

**منجزة كمرحلة تأسيسية فقط؛ إعادة التصميم الكاملة لم تكتمل بعد.** هذه النسخة تبدأ توحيد قواعد التصميم وتضع خريطة للصفحات. لم تتغير قواعد العمل أو الصلاحيات أو مخططات قاعدة البيانات.

## ما نُفذ داخل المشروع

1. جُمعت تعريفات `:root` العامة في كتلة واحدة في مقدمة `employee_movements/static/css/app.css`. التغييرات الخاصة بعرض القائمة ضمن `@media` بقيت مكانية لأنها قواعد استجابة وليست مصدرًا مستقلًا للهوية.
2. أُضيف مقياس موحّد للمسافات والطباعة وارتفاع عناصر التحكم، إضافة إلى رموز لسطوح التطبيق والحدود والظلال والهوية الجانبية وشاشة الدخول.
3. تحسنت قابلية القراءة في القائمة الجانبية، ومعلومات المستخدم، وعناصر الرأس، والحقول والأزرار والجداول والنصوص المساعدة.
4. دُمج تعريفان متكرران لزر «اسأل بسيوني» داخل تنبيهات الإدارة في تعريف أساسي واحد، مع حالات hover وfocus واضحة.
5. أُصلح انضغاط وصف بطاقة طباعة المأمورية عند عرض 320 بكسل، عن طريق تحويل البطاقة إلى تخطيط عمودي على الهواتف الضيقة.
6. جرى تحديث `VERSION.md` و`pyproject.toml` و`employee_movements.__version__` وروابط cache-busting في القالب المشترك إلى `68.23.0`.
7. أُنشئت خريطة تقنية للقوالب الـ45، تتضمن المجموعة وعناصر التحكم والقالب الأب وملفات Python التي تستخدم `render_template` مباشرة حين يمكن اكتشاف ذلك نصيًا.

## نتائج الاختبارات المنفذة

- `contract_tests`: **150 اختبارًا ناجحًا**.
- تحليل CSS متداخل باستخدام `tinycss2`: **صفر أخطاء نحوية**.
- تعريفات `:root` العامة المستقلة: **1**.
- معاينات HTML ثابتة لصفحات الرئيسية والإدارة والدخول عند عروض 1440 و390 و320 بكسل: **9 حالات عرض**؛ لم يظهر تجاوز أفقي للوثيقة ولم تُسجل أخطاء `pageerror`.
- أُعيد توليد المعاينات باستبدال CSS المضمن في لقطات HTML ثابتة سابقة بملف CSS الحالي. **هذه ليست جلسة Flask حية، ولقطات المحتوى قد تحتوي بيانات توضيحية قديمة؛ لا تُستخدم للتحقق من سياق المحافظة أو الصلاحيات أو بيانات الإنتاج.**

## ما لم يُختبر

محاولة تشغيل `tests/` توقفت قبل بدء الاختبارات بسبب عدم توفر Flask (`ModuleNotFoundError`). لم تتوفر أداة `ruff` في البيئة. لم يُشغّل التطبيق بخادم وقاعدة بيانات، ولم تُختبر كل القوالب على بيانات وأدوار حقيقية، ولم تُنشر النسخة.

## ملاحظات تقنية مهمة

ملف CSS لا يزال كبيرًا: نحو 283 KB، ويحتوي 95 كتلة `@media` و664 استخدامًا لـ`!important`. جُمعت الرموز العامة، لكن لم يُحذف بعد التكرار التاريخي في جميع الصفحات؛ هذا مقصود كي لا نحذف قواعد تعتمد عليها قوالب لم تُراجع بصريًا بعد. التنظيف الحقيقي لهذه القواعد يأتي بعد نقل كل مجموعة صفحات إلى المكونات الموحدة، ثم إثبات أن القاعدة القديمة غير مستخدمة.
