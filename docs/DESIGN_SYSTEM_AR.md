# مواصفات التصميم الموحد — نظام إدارة حركات الموظفين

## الأدوار وسياق العمل
- مسؤول التطبيق: الصفحات التشغيلية تبدأ باختيار محافظة، ثم يعمل داخلها مثل مشرف المحافظة. الإدارة خاصة به فقط.
- Manager Application Support: الصفحات التشغيلية تبدأ باختيار محافظة، ثم يعمل داخلها مثل مشرف المحافظة. لا يرى الإدارة.
- مشرف المحافظة: يعمل مباشرة داخل المحافظات المسندة إليه، وله بند تفويض مستقل.
- المدخل الأول: دور تنظيمي مرتبط بموظف موجود، وليس حساب دخول مستقل.

## التنقل
- مسؤول التطبيق: الرئيسية / الموظفون / الحركات / تقارير ومأموريات / الإدارة / حسابي.
- Manager Application Support: الرئيسية / الموظفون / الحركات / تقارير ومأموريات / حسابي.
- مشرف المحافظة: الرئيسية / الموظفون / الحركات / تقارير ومأموريات / تفويض / حسابي.
- المدخل الأول: لا حساب دخول.

## مبدأ التصميم
منتج SaaS عربي حديث: هادئ، واضح، قليل الازدحام، RTL، Cairo، بطاقات صغيرة، حالات واضحة، إجراءات داخل قوائم مختصرة، ومساحات محسوبة.
