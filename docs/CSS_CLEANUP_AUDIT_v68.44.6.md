# تدقيق تنظيف CSS عبر أوراق الأنماط — v68.44.6

## مصدر المشكلة

كانت أدوات الإصدارات السابقة تبحث داخل كل ملف CSS على حدة، ولذلك لم تكن ترصد التصريحات التي يعاد تعريفها في ملف آخر. بينما يحمل `base.html` `design-system-cyan.css` بعد `app.css` وبعد ملفات صفحات العمل المشروطة، ما يجعله مصدرًا لاحقًا مشتركًا لبعض المحددات والخصائص.

## طريقة التنظيف

يبحث `scripts/cleanup_cross_stylesheet_shadow_v68_44_6.py` عن تصريحات مصدرها أحد الملفات المحملة قبل ورقة التصميم العامة. لا يحذف التصريح إلا إذا وجد تعريفًا لاحقًا في `design-system-cyan.css` للمحدد المفرد نفسه، والخاصية نفسها، وسياق at-rule نفسه، وبأهمية مساوية أو أعلى.

تبقى القواعد خارج التنظيف عند وجود محددات مجمعة أو تعليقات أو أخطاء تحليل أو قواعد متداخلة أو تكرار الخاصية داخل القاعدة ذاتها. لا تتقاطع قواعد مختلفة السياق، ولا تُستخدم أوراق CSS المشروطة المحملة بعد النظام العام كدليل عالمي.
