# v49.9 — Canonical Component Audit

- تحويل مجموعات المكونات المتخصصة إلى أسماء Design System معيارية مع إبقاء الكلاسات الدلالية اللازمة للـhooks.
- المكونات الموحدة: بطاقة العنصر، ملخص التقرير، بطاقة الاختصار، بطاقة الهيكل، مجموعة الفروع، قوائم الاختيار، والقائمة متعددة الاختيارات.
- إزالة الاعتماد البصري على aliases العامة القديمة `panel` و`card`.
- لا تغيير في منطق الصلاحيات أو نطاق التشغيل أو مسارات التطبيق.
- Jinja/Python/CSS validation مطلوبة قبل التسليم.
