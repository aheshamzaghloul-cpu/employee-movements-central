# v68.31.0 — تجميع الخيارات المترابطة

## الهدف

تطبيق قواعد عرض موحدة تجعل الحقول والإجراءات التي تخدم هدفًا واحدًا مجموعة واضحة، وتُبقي الخيارات التابعة مع سياقها، وتفصل الإجراءات عن حقول الإدخال.

## التغييرات

- إعادة تنظيم تعديل الموظف إلى مجموعات: الهوية، البيانات الوظيفية، جهة العمل، وبيانات الاتصال.
- تنظيم تعديل المأمورية ومراجعة طلب تعديلها إلى مجموعات جهة/موظف، ومدة، وقرار وملاحظات.
- توضيح أن تاريخ نهاية مأمورية مفتوحة في شاشة الطباعة تاريخ مؤقت للطباعة فقط.
- تنظيم تحويل الموظف إلى مدخل أول، والاستبدال الإداري، والقوائم المرجعية داخل مجموعات معنونة.
- تقسيم إنشاء التفويض إلى أطراف ونطاق التفويض، ثم مدة التفويض.
- تجميع مرشحات المأموريات بحسب الموظف/فرعه الأساسي، مع فصل جهة المأمورية وحالتها والتاريخ داخل «تصفية إضافية».
- تجميع سجل الحركات بحسب نطاق الموظف، ثم نوع الحركة والبحث النصي.
- تجميع المحافظة والفرع في دليل الموظفين داخل عنصر نطاق واحد مع الحفاظ على البحث الحر كاختيار أساسي.
- فصل مطابقة أعمدة Excel الأساسية عن الحقول الاختيارية للموظفين.
- تجميع عناصر دليل الموظفين المتعلقة بالمحافظة والفرع في كتلة «النطاق» مع بقاء البحث السريع ظاهرًا.
- إضافة قواعد CSS مشتركة قابلة لإعادة الاستخدام، مع تصغير متدرج وتنسيق مناسب للهاتف.

## المحافظة على السلوك

لم تُغيّر أسماء الحقول أو قيم POST أو مسارات الخادم أو قواعد الصلاحيات؛ التعديل تنظيمي/عرضي فقط. يستمر اختيار المحافظة في تحديث خيارات الفرع، ويبقى مكان العمل الأساسي منفصلًا عن جهة المأمورية حتى يسمح الانتداب بالعبور بين المحافظات حسب صلاحية المستخدم.

## التحقق

أضيف `contract_tests/test_related_option_groups_v68_31_0.py` لفحص المجموعات الدلالية واتساق الإصدار. اجتازت اختبارات العقود `231/231`، وتحليل القوالب `45/45`، وتجميع Python `160/160`، وتحليل CSS `6/6`، وفحص JavaScript `8/8`. يظل التشغيل الحي واختبار قاعدة بيانات فعلية مطلوبين قبل النشر لأن Flask غير مثبت في بيئة المراجعة.
