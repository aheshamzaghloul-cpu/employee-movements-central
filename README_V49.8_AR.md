# v49.8 — توحيد البنية الداخلية لـ Design System

هذه النسخة لا تضيف طبقة ألوان جديدة فوق النسخ السابقة؛ بل تنظف طبقة CSS نفسها.

## ما تم
- تجميع Utilities المشتركة في مكان واحد وتعريفها مرة واحدة فقط.
- إزالة التعريفات المكررة لبعض أدوات المسافات والشبكات والعرض.
- تثبيت ترتيب منطقي لطبقات CSS:
  1. Design Tokens
  2. App Shell
  3. لغة الصفحات المشتركة
  4. المكونات العامة
  5. مكونات الوحدات المتخصصة
  6. Utilities
  7. Responsive / Accessibility
- الإبقاء على كلاسات الصفحات المستخدمة كـ hooks للـ JavaScript أو كدلالات للصفحة، دون اعتبارها Design System مستقلاً.
- عدم تعديل منطق Flask أو قاعدة البيانات أو الصلاحيات.

## التحقق
- فحص قوالب Jinja.
- فحص Python compile.
- فحص توازن أقواس CSS.
- فحص عدم عودة مراجع أجيال التصميم القديمة.
