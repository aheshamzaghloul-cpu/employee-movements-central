# v49.11 — تدقيق الصفحة الرئيسية

- توحيد تخطيط الصفحة الرئيسية في شبكة واضحة ومتجاوبة.
- منع التفاف أعمدة الصفحة الرئيسية بشكل غير مقصود على الشاشات المكتبية.
- تحسين عرض نتائج البحث العالمي داخل الصفحة الرئيسية.
- إظهار المحافظة والفرع في نتيجة الموظف.
- الحفاظ على البحث العالمي مستقلاً عن نطاق التشغيل.
- الحفاظ على عرض الموظفين ذوي الحركات النشطة فقط في حالة الموظفين الآن.
- تحسين الاستجابة للشاشات المتوسطة والصغيرة.
