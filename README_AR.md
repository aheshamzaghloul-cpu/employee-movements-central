# نظام حركات الموظفين المركزي — v10

نسخة مهيأة للنشر المركزي عبر الإنترنت باستخدام Flask + PostgreSQL + Caddy HTTPS.

- لا توجد بيانات موظفين/فروع/محافظات مستوردة من Excel.
- المستخدمون يدخلون من المتصفح عبر رابط واحد.
- PostgreSQL غير مكشوف للعامة.
- Caddy يتولى HTTPS تلقائيًا بعد توجيه DNS وفتح 80/443.
- توجد أدوات نسخ واستعادة لقاعدة البيانات.

راجع `DEPLOYMENT_AR.md` للتشغيل على السيرفر.
