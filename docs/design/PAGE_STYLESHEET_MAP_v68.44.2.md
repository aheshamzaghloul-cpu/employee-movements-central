# خريطة تحميل التنسيقات — v68.44.2

| ملف التنسيق | شرط التحميل | المسؤولية |
|---|---|---|
| `static/css/app.css` | كل الصفحات التي تستخدم `base.html` | الإطار الأساسي ومصدر متغيرات التصميم الوحيد (`:root`) والتوافق المشترك |
| `static/css/pages/home.css` | المسار `/` | مكونات الرئيسية فقط |
| `static/css/pages/employee-directory.css` | المسار `/employees` | دليل الموظفين والبحث |
| `static/css/pages/movement-forms.css` | مسارات تسجيل/تعديل الحركات والمأموريات المحددة في `base.html` | النماذج التشغيلية المتخصصة |
| `static/css/pages/management.css` | `/structure*`, `/users*`, `/delegations*` | الإدارة والمستخدمون والتفويض |
| `static/css/pages/workspace-pages.css` | مجموعات صفحات العمل المحددة شرطيًا في `base.html` | الجداول ومساحات العمل العامة |
| `static/css/design-system-cyan.css` | صفحات `base.html` | قواعد المكونات المشتركة والهوية؛ لا يعيد تعريف `:root` |
| `static/css/pages/admin-reports-assistant.css` | `/structure*`, `/users*`, `/delegations*`, `/reports*`, `/manager*`, `/audit*` | تحسينات محصورة بالإدارة والتقارير والمدير والتدقيق |
| `static/css/pages/assistant-dock.css` | عند وجود مستخدم مسجل الدخول (`me`) | المشغّل الأيقوني ولوحة المساعد والمحادثة |

## قواعد التصميم

- متغيرات الهوية موجودة في `app.css` فقط، وتُستخدم عبر `var(--...)` كلما كان ذلك عمليًا.
- يُحمّل `design-system-cyan.css` بعد الأنماط الخاصة بالصفحات ليطبق قواعد المكونات المشتركة، لا ليعيد تعريف مجموعة رموز ثانية.
- تبقى قوالب الطباعة الرسمية مستقلة عن واجهة مساحة العمل.
- ما زالت هناك محددات متكررة في ملفات CSS التاريخية؛ لم تُحذف آليًا حين اختلفت التصريحات، لأن ذلك يتطلب معاينة مرئية وتحققًا من السلوك النهائي.
