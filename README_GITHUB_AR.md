# نظام حركات الموظفين المركزي

نسخة النشر المركزي على الإنترنت.

- Flask + PostgreSQL
- Docker / Gunicorn
- HTTPS عبر Caddy
- قاعدة البيانات لا تُفتح مباشرة للإنترنت
- بيانات الأعمال تبدأ فارغة؛ لا توجد بيانات سوهاج القديمة ضمن المشروع

## ملاحظة أمنية
هذا المستودع يجب أن يكون **Private**.
لا ترفع ملفات `.env` أو كلمات المرور أو مفاتيح سرية إلى GitHub.
