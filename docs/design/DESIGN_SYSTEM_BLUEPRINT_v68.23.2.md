# مخطط الانتقال إلى نظام التصميم الموحد — v68.23.2

## المرحلة الحالية

- `v68.23.0`: تأسيس رموز التصميم الأساسية وفهرس الصفحات.
- `v68.23.1`: إعادة تنظيم الرئيسية ودليل الموظفين.
- `v68.23.2`: إعادة تنظيم نماذج الحركات وتعديل المأموريات ومراجعة طلبات Manager.

## خطوات المتابعة

1. إنهاء مجموعات النماذج الحالية بعد تشغيل اختبار Flask/قاعدة بيانات مرحلية.
2. إعادة تنظيم التقارير وجداول البيانات والتصدير والطباعة.
3. إعادة تصميم مركز الإدارة والمستخدمين والأدوار والصلاحيات والتفويضات.
4. توحيد مركز المساعد والتنبيهات والأوامر السريعة وحالات الانتظار والفشل.
5. حذف قواعد CSS القديمة بعد التحقق من عدم استخدامها عبر جميع القوالب، لا بالاستدلال على التكرار فقط.
6. تشغيل اختبارات الانحدار لكل الأدوار والمسارات والمقاسات، ثم اعتماد التصميم الكامل.

## قواعد التنفيذ

- لا تنشأ طبقة ترقيع CSS مستقلة لكل صفحة؛ تبقى رموز الأساس والمكوّنات المشتركة في المصدر المركزي، وقواعد الصفحة في ورقة نطاقية تُحمّل حسب المسار.
- كل تغيير بصري يرافقه تحقق من الحقول ومسارات POST والصلاحيات والبحث والتصدير والطباعة.
- المعاينات الثابتة دليل على العرض فقط، ولا تعد إثباتًا لسلوك Flask أو PostgreSQL.
- لا يُنشر الإصدار ولا تُلمس قاعدة الإنتاج ضمن مراحل المراجعة.
