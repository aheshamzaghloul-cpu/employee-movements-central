# خريطة أوراق التصميم — v68.23.1

| الصفحة/المسار | ورقة CSS | الغرض |
|---|---|---|
| كل صفحات التطبيق | `employee_movements/static/css/app.css` | قواعد الإطار المشترك والرموز الأساسية والتوافق مع القوالب الحالية |
| `/` | `employee_movements/static/css/pages/home.css` | تخطيط الرئيسية، إجراءاتها الرئيسية، حالة الموظفين، والمدخلون الأوائل |

تُحمّل الأوراق الخاصة بالصفحتين من `base.html` بشرط المسار، مع إصدار cache-busting ثابت `68.23.1`. لا تستخدم أوراق الصفحتين كقواعد عامة للصفحات الأخرى؛ حافظ على بادئات `.ds-home-*` و`.ds-directory-*` لتقليل التداخل.

## تحذيرات مراجعة

- محتوى المعاينات مبني على قوالب Jinja2 الفعلية مع سياق اختبار اصطناعي، ولا يعكس بيانات الإنتاج أو صلاحيات مستخدم حقيقي.
- لم يجرِ تشغيل Flask في بيئة البناء الحالية، لذلك يجب مراجعة العرض مرة أخرى في CI/بيئة مرحلية.
- لا يزال `app.css` يحتاج تنظيفًا لاحقًا؛ لم تُحذف قواعده التاريخية غير المستخدمة بالتخمين.
