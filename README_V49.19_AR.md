# v49.19 — إصلاح مسؤول التطبيق والمدخلين الأوائل

- تم تثبيت قاعدة أن «المدخل الأول» دور تنظيمي للموظف وليس دور دخول للحساب.
- تم منع اختياره ضمن أدوار الحسابات الجديدة/تعديل الحسابات.
- تم منع اختياره من مبدّل الأدوار، حتى لا ينتقل مسؤول التطبيق إلى سياق يفقده الإدارة وتعديل الحساب.
- تم تنفيذ تنظيف لمرة واحدة لإزالة «المدخل الأول» إذا كان قد أضيف بالخطأ إلى حساب مسؤول التطبيق، مع الإبقاء على بيانات الموظف/التنظيم إن وجدت.
- تم الإبقاء على «مشرف محافظة» الموازي لمسؤول التطبيق، بحيث يظهر اسم مسؤول التطبيق ضمن المشرفين عند إدارة المدخلين الأوائل.
- تم تحديث رقم الإصدار الظاهر في الواجهة إلى 49.19.
