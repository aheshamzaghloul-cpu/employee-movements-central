# خريطة أوراق التصميم — v68.25.0

| ورقة التصميم | المسارات | المسؤولية |
|---|---|---|
| `app.css` | عام | رموز الألوان والمسافات، الغلاف الجانبي، الشريط العلوي، عناصر الواجهة الأساسية والتفاعل المشترك |
| `pages/home.css` | `/` | الصفحة الرئيسية وبحث الموظف والإجراءات الذكية |
| `pages/employee-directory.css` | `/employees` | فهرس الموظفين وفلاتر الدليل |
| `pages/movement-forms.css` | `/movements*`، محرر المأمورية وطلبات تعديلها | نماذج تسجيل/تعديل الحركات والتحقق المرئي وحالات الخطوات |
| `pages/management.css` | `/structure`، `/users*`، `/delegations` | الإدارة والمستخدمون والصلاحيات والتفويضات |
| `pages/workspace-pages.css` | القوائم الأساسية، استيراد Excel، التقارير، لوحة المدير، الإشعارات، الحساب، تفاصيل الموظف والاستبدال وسجل العمليات | تغطية المساحات التي لم تكن لديها ورقة متخصصة، وفق `data-workspace-path` |

تحمّل صفحات الواجهة ورقة `app.css` أولًا، ثم الورقة المتخصصة عندما يطابق المسار. يستثني شرط التحميل الفرعي نماذج تعديل المأمورية وطلبات التعديل من `workspace-pages.css` كي تحتفظ بتنسيق النماذج المتخصص. قوالب الطباعة الرسمية المستقلة لها CSS مخصص للطباعة ومقاس الورق، لذلك تظل خارج إعادة تصميم واجهة التشغيل.
