# تدقيق تنظيف CSS — v68.44.3

## السياسة المستخدمة

1. لا يُحذف محدد لأنه مكرر بالاسم فقط.
2. تُزال قاعدة كاملة فقط إذا تطابقت قائمة المحددات والتصريحات المهمة والقيم والسياق الشرطي داخل ورقة الأنماط نفسها.
3. يُزال تصريح لاحق بالقيمة نفسها فقط عندما يطابق المحدد الفردي والسياق الشرطي نفسه ويكون ترتيب الأولوية مناسبًا؛ يتم تجنب التصريحات المتكررة داخل قاعدة واحدة حتى لا تنكسر fallbacks.
4. تُحفظ الحالات المتعمدة مثل قواعد الهاتف والطباعة والحالات النشطة وخصائص التوافق.
5. تثبيت المظهر يتم بمقارنة معاينات Chromium محلية عند 1440×1000 و390×844، باستخدام بيانات تجريبية.

## إصلاح ظهر أثناء المراجعة المرئية

كان `base.html` لا يحمّل `pages/movement-forms.css` على المسار `/missions/from-screenshot`، رغم أن قواعد الصفحة تعتمد عليه لضبط أبعاد SVG. أدى ذلك إلى ظهور أيقونة الخصوصية بحجم افتراضي أسود كبير على الهاتف. أُضيف المسار إلى شرط التحميل، وأصبحت الأيقونة 18×18px بخط أزرق. أضيف اختبار عقد يثبت هذا الشرط.

## ما يجب عدم حذفه آليًا

- fallback بين `overflow-x: hidden` و`overflow-x: clip` داخل القاعدة نفسها.
- القواعد داخل `@media`, `@supports`, `@print` أو حالات hover/focus/active عندما تكون السياقات مختلفة.
- قيم الحالة التي تبدو متشابهة ولكنها تخص النجاح والتحذير والخطر أو حالة سجل محددة.
- قواعد الطباعة الخاصة بالنموذج الرسمي.
