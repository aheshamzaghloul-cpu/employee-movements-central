# تقرير المراجعة المستقلة — v68.44.1

## سبب المراجعة

أظهرت المراجعة المستقلة للإصدار `v68.44.0` أن ورقة `admin-reports-assistant.css` كانت تُحمّل عالميًا، بما في ذلك الصفحات التي لا تحتاج إلى تنسيقات الإدارة والتقارير، وكانت تجمع معها تنسيقات المساعد المتاح عبر مساحة العمل. لم يكن ذلك كسرًا وظيفيًا معروفًا، لكنه يزيد نطاق CSS ويجعل العزل بين عائلات الصفحات أقل وضوحًا.

## الإصلاح

- فصل تنسيقات المساعد وواجهة المحادثة إلى `static/css/pages/assistant-dock.css`.
- الإبقاء على تنسيقات الإدارة/المستخدمين/التفويض/التقارير/مركز المدير/سجل التدقيق في `admin-reports-assistant.css`.
- تحميل ورقة الإدارة والتقارير فقط عند الطلبات التي تبدأ بـ`/structure` أو `/users` أو `/delegations` أو `/reports` أو `/manager` أو `/audit`.
- تحميل ورقة المساعد فقط عندما تكون هناك جلسة مستخدم (`me`)، لأن المساعد جزء من مساحة العمل المسجلة الدخول.
- تحديث رقم الإصدار وروابط الأصول إلى `68.44.1`، وإضافة عقود انحدار لتحميل CSS المشروط.
- إنشاء الحزمة النهائية بجذور المشروع مباشرة داخل ZIP، دون مجلد أب إضافي، لتسهيل الاستبدال؛ مجلد `.github` وملفات المشروع الأساسية موجودة في جذر الأرشيف.
