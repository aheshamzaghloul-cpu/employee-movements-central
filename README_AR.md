# نظام إدارة حركات الموظفين المركزي — v32.4 FINAL REVIEWED

نسخة مركزية عبر الإنترنت بواجهة عربية RTL.

## أهم التحديثات في v32.4
- الاختيارات المتعددة أصبحت داخل قوائم منسدلة منظمة بدل عرض جميع الخيارات دائمًا.
- نوع الحركة، الموظف، نوع الإجازة، الفرع، المعتمد، والفترات تستخدم قوائم منسدلة عند الحاجة.
- يجب تحديد **اسم المعتمد** عند حفظ الحركة، ويمكن تغييره قبل الاعتماد وحتى بعد إرسال الحركة للمراجعة، مع تسجيل التغيير في السجل.
- حسابات مسؤول التطبيق ومشرف المحافظة والمدخل الأول تحتوي على **الكود الوظيفي**.
- تم إلغاء إدخال **كود الموظف** من شاشة تسجيل الموظف؛ ويظل **الكود الوظيفي** مطلوبًا.
- خلفية التطبيق أصبحت أفتح مع الحفاظ على المظهر المهني الأزرق الرمادي.
- جميع حقول التسجيل المطلوبة تتحقق منها الواجهة والخادم، بما في ذلك الحقول الشرطية للحركات.
- لا يتم حذف بيانات PostgreSQL أو الموظفين أو الحركات بسبب هذه التحديثات.
