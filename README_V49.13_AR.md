# v49.13 — Design System لوحدة الحركات

توحيد بصري وتشغيلي لصفحات الحركات وتعديل الحركة وسجل الحركة، مع الحفاظ على الكلاسات الدلالية اللازمة للسلوك وJavaScript.

- صفحة الحركات: الفلاتر، الحركات الحالية، المتابعة، سجل الحركات.
- تعديل الحركة: نموذج موحد ودعم الانتداب المفتوح.
- سجل الحركة: ملخص وسجل تدقيق موحد.
- إجراءات الحركة: قائمة موحدة تعتمد SVG.
- Responsive للشاشات المتوسطة والهاتف.
