# v49.22 — مركز التحكم في الشخص

تم تطوير إدارة الحسابات لمسؤول التطبيق بحيث تعرض الشخص الواحد في بطاقة تحكم واحدة تشمل:
- الهوية وبيانات الحساب.
- جميع الأدوار التقنية والتشغيلية.
- المحافظات المسندة للمشرف.
- الفروع المرتبطة بدور المدخل الأول.
- تكليف المدخل الأول التنظيمي والمشرف المسؤول عنه.
- الحسابات الموازية للأدوار.
- حالة الحساب والصلاحيات.
- زر مباشر لتعديل الشخص بالكامل.

كما تم توضيح أن «المدخل الأول» تكليف تنظيمي ولا يحتاج حساب دخول مستقل.
