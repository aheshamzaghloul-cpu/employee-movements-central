# تقرير الإصدار v68.31.0 — تجميع الخيارات المترابطة

## النتيجة

أُضيف نظام موحّد لتجميع الحقول والإجراءات حسب وظيفتها، مع عناوين واضحة وتلميحات قصيرة وتخطيط متجاوب. الفكرة ليست إخفاء الخيارات الضرورية، بل توضيح علاقاتها وتقديم التابع بعد الأساسي.

## الصفحات التي عُدّلت

- **تعديل الموظف:** هوية الموظف، البيانات الوظيفية، جهة العمل، وبيانات الاتصال.
- **إنشاء التفويض:** المشرف والمحافظة والبديل ضمن مجموعة أطراف ونطاق، والتاريخان ضمن مجموعة مدة التفويض.
- **تسجيل/تصفية الحركات:** خطوات إنشاء الحركة بقيت تدريجية، وصارت فلاتر السجل تقسم نطاق الموظف عن النص ونوع الحركة.
- **تقارير الانتداب وتقارير الحركات:** المحافظة والفرع والموظف مجموعة أساسية، بينما وجهة المأمورية والحالة والفترة خيارات إضافية مستقلة.
- **التجميع الشهري:** اختيار الشهر منفصل بصريًا عن العرض والتصدير.
- **استيراد Excel:** فصل الحقول المطلوبة عن حقول الموظفين الاختيارية دون تغيير اشتراطات POST.
- **إضافة المدخل الأول:** فصل تحديد الشخص والمشرف عن قائمة الفروع المسندة.
- **دليل الموظفين:** المحافظة والفرع داخل مجموعة نطاق واحدة، مع إبقاء البحث الحر هو الحقل الأوضح.
- **تعديل المستخدم:** إبراز مجموعة بيانات الهوية منفصلة عن الأدوار والنطاق والصلاحيات، وهي مجموعات كانت موجودة أصلًا وأصبحت متناسقة بصريًا.

## ما لم يتغير

لم تتغير أسماء الحقول أو قيم النماذج أو المسارات أو سياسات الوصول في هذه المرحلة. اختيار محافظة الموظف لا يقيّد وجهة الانتداب؛ الوجهة ما زالت مستقلة وتخضع لقواعد الصلاحيات الأصلية. ولم تُحذف أي بيانات أو خيارات لازمة.
