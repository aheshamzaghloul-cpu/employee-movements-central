# خريطة انتقال التصميم الموحد — v68.23.0

## الهدف

الانتقال من قواعد CSS متراكمة إلى نظام تصميم مركزي قابل للصيانة، مع الحفاظ على وظائف Flask/Jinja والصلاحيات ونطاق المحافظة وسلوك البحث والتصدير والطباعة والمساعد الذكي.

## تشخيص خط الأساس

- قوالب HTML: **45**.
- ملف CSS الرئيسي: **282,986 بايت**، ونحو **2,900 سطر**.
- كتل `@media`: **95**.
- استخدامات `!important`: **664**.
- رموز فئات CSS الفريدة تقريبًا: **825**.
- عناصر `<style>` المضمنة داخل القوالب: **2**.
- عناصر `<script>` المشار إليها/المضمنة داخل القوالب: **18**.

هذه مؤشرات حجم وتعقيد فقط؛ لا تُحذف القواعد أو القوالب اعتمادًا على العدّ وحده.

## ما تغير في هذه المرحلة

1. جُمعت تعريفات `:root` العامة في موضع مركزي واحد، مع إبقاء تعديلات متغير عرض الشريط داخل نقاط الاستجابة فقط.
2. أضيفت رموز موحدة للمسافات، والأحجام الطباعية، وارتفاعات عناصر التحكم، وحدود الحالات، والطبقات/الظلال، مع الإبقاء على أسماء `--ui-*` القديمة لتوافق القوالب.
3. حسّنت الأحجام الدنيا للنصوص داخل التنقل والرأس والحقول والأزرار والجداول، وأزلت اختلاف مظهر روابط «اسأل بسيوني» داخل تنبيهات الإدارة.
4. تم تحديث رقم الإصدار وروابط التخزين المؤقت إلى `68.23.0` دون تعديل قواعد العمل أو الصلاحيات.
5. أُنشئت قائمة آلية بكل القوالب والمكوّنات/العناصر التي تحتويها لتكون مرجع المراحل التالية.

## ترتيب تنفيذ إعادة التصميم

### المرحلة A — نظام التصميم والإطار العام (هذه الحزمة)

- توحيد المتغيرات الأساسية والتسلسل الطباعي والارتفاعات.
- تثبيت أحجام القائمة الجانبية والعنوان والشريط العلوي.
- توحيد البطاقات والحقول والأزرار والجداول والتنبيهات على مستوى المكوّنات المشتركة.
- فحص RTL والتركيز والتنقل بلوحة المفاتيح وتقليل الحركة.

### المرحلة B — الرئيسية ودليل الموظفين

- إعادة ترتيب الإجراءات الأساسية حسب أولوية الاستخدام.
- الفصل بين البحث الشامل عن الموظف ونطاق محافظة العمل.
- ضبط نتائج البحث والحالة الفارغة والتحميل والتصفية.

### المرحلة C — الحركات والنماذج

- تدفق نموذج الانتداب/الإجازة/الإذن، التحقق بجوار الحقول، المعاينة قبل الحفظ، ورسائل النجاح والفشل.
- الحفاظ على سلوك الانتداب بين المحافظات والطباعة ومتطلبات تاريخ النهاية.

### المرحلة D — التقارير والمأموريات

- فلاتر واضحة، شريط أدوات ثابت عند الحاجة، جداول متجاوبة، وتنسيق طباعة مستقل.
- مطابقة النتائج المعروضة والمصدّرة.

### المرحلة E — الإدارة والمستخدمون والصلاحيات

- تنظيم مركز الإدارة حسب مجالات العمل، وتوضيح الإجراءات الحساسة، ومراجعة جميع أدوار Admin وManager وSupervisor.

### المرحلة F — تنظيف CSS/JS

- إزالة التكرار بعد نقل الصفحات إلى المكوّنات الموحدة واختبارها.
- جرد القواعد والسكربتات غير المستخدمة بدل حذفها بالتخمين.
- تقليل `!important` على دفعات صغيرة مع لقطات قبل/بعد.

### المرحلة G — اعتماد شامل

- صور مقارنة فعلية لكل قالب/صفحة مهمة عند 1440 و1024 و390 و320 بكسل.
- فحص الألوان والتباين والتركيز ولوحة المفاتيح والنماذج والجداول والطباعة.
- اختبار الأدوار والبيانات بعد كل مجموعة صفحات.
