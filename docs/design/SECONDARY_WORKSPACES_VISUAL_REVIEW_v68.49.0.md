# Secondary Workspaces — Visual Review v68.49.0

## الاتجاه البصري

- هوية سماوية مائلة للأزرق مع نص داكن واضح، وخلفية عمل فاتحة، وتباين محدود باللون الأزرق الداكن في الهيكل الجانبي.
- الحفاظ على توحيد الحقول والبطاقات مع إعطاء كل صفحة ترتيبًا يتناسب مع عملها.

## ما تم ضبطه

- **الحساب وتغيير كلمة المرور:** تقسيم معلومات الحساب عن نموذج كلمة المرور، وعمودان على الشاشات الواسعة يتحولان إلى عمود واحد للهاتف.
- **الإشعارات:** الحالات العاجلة والتحذيرية والمعلوماتية لها تمييز لوني دلالي، مع بطاقات أوضح وسلوك متجاوب.
- **سجل التدقيق:** رأس جدول أوضح، وتناوب خفيف بين الصفوف، وتغليف المحتوى الطويل داخل حاوية الجدول بدل توسيع الصفحة.
- **القوائم الأساسية:** بطاقتا أنواع الحركات وأنواع الإجازات في عمودين متوازنين على سطح المكتب، وفي عمود واحد على الهاتف. توحيد مظهر أزرار الحفظ والتفعيل والتعطيل والحذف.
- **الاستبدال الإداري:** تمييز بصري للنوعين الرئيسيين للعملية دون تغيير حقولها.
- **تعديل المستخدم:** تنظيم أقسام الدور والنطاق والصلاحيات، مع وضوح خيار التحديد الحالي.
- **حالات الخطأ:** بطاقة موحدة ذات خلفية زرقاء فاتحة، وعنوان ورسالة وزر رجوع متسقة مع الهوية. موضع CSS عام كي لا يعتمد على مطابقة عنوان URL.

## ملفات المعاينة

داخل `docs/design/preview-v68.49.0/` توجد معاينات الحاسوب والهاتف والهاتف الضيق لكل من: `account`, `notifications`, `audit`, `lookups`, `replacement`, `user-edit`, و`error`. ملف `preview-summary.json` يدوّن أبعاد الشاشة، وعرض الصفحة المحسوب، وأخطاء كل معاينة وملفات CSS المحملة.

## ملاحظة

هذه لقطات Chromium محلية لقوالب مرجعية تستخدم CSS الحقيقي للمشروع وبيانات اصطناعية. وهي مفيدة لمراجعة تنسيق الواجهة وحالات القص والتمدد الأفقي، لكنها لا تساوي اختبارًا حيًا لقوالب Flask الديناميكية أو لقاعدة البيانات الفعلية.
