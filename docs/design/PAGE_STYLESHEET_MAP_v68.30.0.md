# خريطة التغطية البصرية والتفاعلية — v68.30.0

## طبقات مشتركة

- `static/css/app.css`: رموز التصميم المشتركة، شريط أدوات البحث، مؤشرات عدّ الصفوف، زر «عرض المزيد»، وتنسيق أقسام التصفية القابلة للفتح.
- `static/js/app.js`: البحث المحلي في الجداول الذكية، إظهار أول مجموعة من النتائج، العدّاد، وتوسيع النتائج أو تقليصها؛ كما يدير البحث والعرض التدريجي لبطاقات الأشخاص والتنبيهات التي تحمل `data-progressive-list`.
- `static/css/pages/workspace-pages.css`: التنسيق العام لصفحات التقارير، المأموريات، المدير، التنبيهات، الاستيراد، والصفحات المتبقية التي تستخدم القالب المشترك.
- `static/css/pages/management.css`: مركز الإدارة والمستخدمون والصلاحيات والتفويضات.
- `static/css/pages/movement-forms.css`: نماذج الحركات وتعديل المأموريات وطلبات التعديل؛ سلوك العرض التدريجي لا يغيّر مسارات الحفظ.

## ضوابط السلوك

- «عرض المزيد» يخفي عناصر واجهة فقط؛ لا يحذف سجلات من قاعدة البيانات.
- البحث المحلي يصفّي البيانات المرسلة أصلًا إلى الصفحة، ولا يوسّع نطاق البيانات على الخادم.
- التصدير والعمليات الحساسة تظل مرتبطة بمرشحات الخادم والصلاحيات الحالية.
- لم تتغير نماذج POST أو أسماء حقول الحفظ في هذه المرحلة.
