# نظام حركات الموظفين المركزي — v10

نسخة مهيأة للنشر المركزي عبر الإنترنت باستخدام Flask + PostgreSQL + Caddy HTTPS.

- لا توجد بيانات موظفين/فروع/محافظات مستوردة من Excel.
- المستخدمون يدخلون من المتصفح عبر رابط واحد.
- PostgreSQL غير مكشوف للعامة.
- Caddy يتولى HTTPS تلقائيًا بعد توجيه DNS وفتح 80/443.
- توجد أدوات نسخ واستعادة لقاعدة البيانات.

راجع `DEPLOYMENT_AR.md` للتشغيل على السيرفر.

## v12.0 — الواجهة الرسمية المبسطة
تمت إعادة تنظيم الواجهة لتقليل عدد الاختيارات، وجعل تسجيل الحركة متتابعًا حسب نوعها، وتحسين إدارة الموظفين والفروع والمستخدمين والصلاحيات.


## v12.0 — الصلاحيات المرنة والنطاق الإداري المبسط

- مسؤول التطبيق: إدارة المحافظات والحسابات وكل نطاق النظام.
- مشرف المحافظة: إدارة الفروع داخل محافظاته، وإنشاء وإدارة المدخلين الأوائل، مع صلاحيات قابلة للتخصيص.
- المدخل الأول: إدارة الموظفين والحركات داخل الفروع المسندة إليه.
- كل شاشة إدارية تعرض الإضافة والتعديل والتعطيل والحذف حيث يكون الحذف آمنًا.
- عند وجود سجل تاريخي مرتبط، يتم منع الحذف وتوفير التعطيل للحفاظ على سلامة البيانات.
