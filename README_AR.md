# الإصدار v35.08

يتضمن:
- مساعد محادثي دلالي يعتمد على بيانات التطبيق وسياق المستخدم، ولا يعتمد في مساره الأساسي على كلمات أو جمل محفوظة.
- دعم الانتداب المفتوح فعليًا: بدون تاريخ نهاية، يظهر الموظف في الفرع المنتدب إليه مع علامة «انتداب مفتوح»، وعند إنهائه يعود تلقائيًا لفرع التعيين الأساسي مع بقاء التاريخ محفوظًا.
- ترتيب «حالة الموظفين الآن»: الإجازات ثم الانتدابات محددة النهاية ثم الانتدابات المفتوحة، مع تمييز لوني واضح.
- بحث حركات الموظفين من الرئيسية بالفرع أو بالاسم أو بهما معًا.
