# خريطة تنسيقات الصفحات — v68.45.0

## ترتيب CSS في `base.html`

1. `css/app.css` — متغيرات الهوية والأساس العام.
2. ملفات تنسيق الصفحة المشروطة حسب المسار، مثل `home.css` و`employee-directory.css` و`movement-forms.css`.
3. `css/design-system-cyan.css` — المكونات والنظام المشترك.
4. `css/pages/home-journey.css` — يُحمّل فقط عند `request.path == '/'`، وهو المسؤول عن توزيع الاختصارات ومساحة العمل الجديدة.
5. `css/pages/admin-reports-assistant.css` — للمسارات الإدارية والتقارير ذات الصلة فقط.
6. `css/pages/assistant-dock.css` — للمستخدمين المسجلين دخولهم.

## سياسة الرئيسية الجديدة

- الاختصارات الأربعة هي مدخلات واضحة وليست بديلًا عن النماذج الفعلية.
- `تسجيل حركة` يفتح معالج الحركات المخصص عندما لا يوجد موظف محدد؛ وإذا كان موظف محدد موجودًا ينتقل الاختصار إلى نموذج التسجيل بالصفحة.
- بحث الموظف العام في جميع المحافظات يبقى منفصلًا عن تسجيل الحركة.
- اختيار محافظة العمل يظل في الشريط العلوي فقط؛ لا تُضاف قائمة ثانية داخل الرئيسية.
- تظهر بطاقة مأمورية من المرفق وطباعة المأمورية وفق الصلاحيات القائمة.

## نقاط التحقق

- حاسوب 1440×1000: أربع بطاقات اختصار أفقية ومساحتا تسجيل وبحث متجاورتان.
- هاتف 390×844: الاختصارات شبكة من عمودين ومساحتا التنفيذ والبحث متراصتان رأسيًا.
- ملف CSS الجديد مشروط على الرئيسية فقط؛ بقية الصفحات لا تحمّله.
