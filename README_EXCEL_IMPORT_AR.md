# استيراد البيانات من Excel — v35.35

## الفروع
من صفحة **إدارة الفروع** اختر **إضافة فروع من Excel**.
الأعمدة المطلوبة:
- المحافظة
- اسم الفرع
- كود الفرع

## الموظفون
من صفحة **الموظفون** اختر **إضافة موظفين من Excel**.
الأعمدة المطلوبة:
- المحافظة
- الفرع
- اسم الموظف
- البريد الإلكتروني
- الوظيفة
- الكود الوظيفي
- تاريخ التعيين
- هاتف الشركة
- الهاتف الشخصي

يوجد زر **تحميل نموذج Excel** في كل شاشة.
الاستيراد لا ينشئ سجلات مكررة، وتظهر الصفوف التي تعذر استيرادها مع سبب الخطأ.
