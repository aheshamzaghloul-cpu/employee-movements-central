# خريطة تنسيق الصفحات — v68.29.0

## هدف هذه المرحلة
تقليل ازدحام الاختيارات عبر البحث والتوسيع التدريجي، دون إزالة سجلات أو تغيير صلاحيات الوصول.

| الصفحة | ملفات التنسيق | السلوك المرئي الجديد |
|---|---|---|
| `/movements` | `static/css/app.css` و`static/css/pages/movement-forms.css` | نوع الحركة أولًا، شريط خطوات، بحث فرع/موظف، عداد نتائج، أول 8 عناصر مع «عرض المزيد». |

| `/` — المدخلون الأوائل | `static/css/pages/home.css` و`static/css/app.css` | بحث في قائمة المدخلين، ثم بحث داخل فروع المدخل، ثم بحث داخل موظفي الفرع؛ كل مجموعة تعرض أول 8 عناصر. |

## حدود السلوك
- حدود العرض الأولية هي حدود واجهة فقط؛ البيانات الإضافية تبقى موجودة ويمكن إظهارها.
- الفلاتر واستعلامات API تبقى خاضعة للتحقق الخادمي ونطاق المستخدم.
- بحث الموظف العام في الرئيسية لا يرتبط بمحافظة العمل الحالية.
- الانتداب والمأمورية يحتفظان بنطاق المحافظات الذي يسمح به دور المستخدم، ويُتحقق من النطاق في الخادم.

## فحوص هذه المرحلة
- 209 اختبار عقد ناجح.
- 45 قالب Jinja2، و6 ملفات CSS، و8 ملفات JavaScript اجتازت تحليل الصياغة.
- تم التحقق من السكربتات المضمنة المعدلة في `movements.html` و`home.html` و`employees.html` بعد إحلال قيم الاختبار مكان تعبيرات Jinja.
- اختبار Flask الكامل لم يبدأ لأن حزمة Flask غير متاحة في بيئة المراجعة. لم يتم نشر الإصدار أو تغيير قاعدة بيانات الإنتاج.
