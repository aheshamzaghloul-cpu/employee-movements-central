# نظام إدارة حركات الموظفين — Employee Movements Central

منصة ويب عربية (RTL) مركزية لإدارة **الإجازات والانتدابات والأذون** للموظفين حسب الهيكل التنظيمي (محافظات ← فروع ← مشرفون ← مدخلون أوائل)، مع مأموريات قابلة للطباعة (PDF)، وتقارير، واستيراد Excel، ومساعد ذكي.

**التقنيات:** Flask 3 · Flask-SQLAlchemy · PostgreSQL (أو SQLite للتطوير) · Gunicorn · Docker · Caddy (HTTPS).

## التشغيل السريع (تطوير)

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements-dev.txt
APP_ENV=development ADMIN_PASSWORD='Admin12345' python wsgi.py     # http://127.0.0.1:8000
```

في وضع `development` يُنشأ مفتاح جلسة مؤقت وقاعدة SQLite محلية (`local.db`) تلقائيًا.

## التشغيل بالحاويات (إنتاج)

```bash
cp .env.example .env     # املأ القيم السرية والنطاق
docker compose up -d --build
```

التفاصيل والنسخ الاحتياطي: [docs/DEPLOYMENT_AR.md](docs/DEPLOYMENT_AR.md).

## الإعدادات (متغيرات البيئة)

| المتغير | الوصف |
|---|---|
| `APP_ENV` | `production` (الافتراضي) يرفض الإقلاع بإعدادات غير آمنة، أو `development` / `testing` |
| `SECRET_KEY` | **إلزامي في الإنتاج**، 32 حرفًا على الأقل |
| `DATABASE_URL` | رابط PostgreSQL؛ تُقبل الصيغ `postgres://` و`postgresql://` |

> **مهم:** في الإنتاج `DATABASE_URL` إلزامي ويجب أن تشير إلى PostgreSQL ثابتة. لا يستخدم التطبيق SQLite في الإنتاج حتى لا تضيع الحسابات والبيانات عند إعادة النشر.
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | حساب المسؤول الأولي (يُنشأ عند أول تشغيل فقط) |
| `COOKIE_SECURE` | `1` عند العمل عبر HTTPS |
| `GEMINI_API_KEY` / `GEMINI_MODEL` / `GEMINI_TIMEOUT` | للمساعد الذكي. النموذج الافتراضي `gemini-3.8-flash`. Gemini يفهم الطلب فقط؛ التطبيق يحل الكيانات ويتحقق من الصلاحيات وينفذ التغيير محليًا. لا تُرسل له كتالوجات الموظفين أو الفروع. |
| `LOGIN_RATE_LIMIT` / `ASSISTANT_RATE_LIMIT` | حدود الاستخدام (انظر `.env.example`) |

## النشر على Blitz.cloud

1. ارفع المشروع إلى GitHub في المستودع الذي سيقرأه Blitz.
2. في Blitz أضف متغيرات البيئة من **Environment** ولا تضع الأسرار في GitHub.
3. المطلوب في الإنتاج: `SECRET_KEY` و`DATABASE_URL`. ولتشغيل المساعد: `GEMINI_API_KEY`، ويمكن ترك `GEMINI_MODEL` على `gemini-3.8-flash`.
4. بعد حفظ المتغيرات أعد تشغيل التطبيق.
5. يجب أن يعيد `/healthz` الحالة `ok` قبل اختبار تسجيل الدخول.

المساعد يستخدم Gemini لفهم اللغة فقط، ثم يبحث عن الموظف/الفرع/المحافظة/الحساب/الحركة في قاعدة البيانات المحلية، ويعيد فحص الصلاحيات والبيانات قبل التنفيذ. يمكن لمسؤول التطبيق تنفيذ إدارة الموظفين والمحافظات والفروع والحسابات والأدوار والنطاقات والمدخلين الأوائل والتفويضات والقوائم والحركات من المحادثة، وكل تغيير يمر بالمعاينة والتأكيد ثم يسجل في Audit/MovementHistory. لا تُحفظ كلمات المرور المؤقتة داخل جلسة المتصفح.

  hooks.py           CSRF وترويسات الأمان وسياق القوالب

  templates/  static/
tests/   docs/   scripts/
