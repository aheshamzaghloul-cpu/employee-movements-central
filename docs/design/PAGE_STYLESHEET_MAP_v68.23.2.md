# خريطة أوراق التصميم — v68.23.2

- `static/css/app.css`: إطار التطبيق المشترك، القائمة الجانبية والرأس، رموز التصميم، قواعد عامة ومسارات الاستجابة. يحتوي أيضًا على قص تجاوز الاتجاه الأفقي الناتج عن القائمة المغلقة خارج مساحة العرض.
- `static/css/pages/home.css`: الصفحة الرئيسية، يُحمّل فقط عندما يكون `request.path == '/'`.
- `static/css/pages/employee-directory.css`: دليل الموظفين، يُحمّل فقط عندما يكون `request.path == '/employees'`.
- `static/css/pages/movement-forms.css`: تسجيل/عرض الحركات وتعديل الحركة وتعديل المأمورية ومراجعة طلبات تعديلها، يُحمّل فقط لمسارات `/movements*` و`/reports/assignments/mission-edit*` و`/reports/assignments/edit-requests*`.

تأتي الأوراق الخاصة بعد `app.css` لتسمح بتخصيص الصفحة من دون تكرار الإطار الأساسي. لا تُحذف قواعد CSS القديمة إلا بعد اختبار القوالب الـ45 وأخذ صور مقارنة عبر الحاسوب والهاتف.
