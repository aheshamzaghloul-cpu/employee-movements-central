### v49.5 — تنظيف وتوحيد طبقة Design System

هذه النسخة هي مرحلة تنظيف تقنية بعد توحيد الصفحات في v49.4. الهدف هو إزالة آثار طبقات CSS المتراكمة وجعل `design49.css` قائمًا على مجموعة tokens موحدة `--ds-*` بدل وجود نظامي ألوان متداخلين.

## ما تم
- توحيد tokens: الخلفية، الأسطح، النصوص، الحدود، الأزرق، الأخضر، الكهرماني، البنفسجي، الأحمر، الزوايا والظلال.
- إزالة root قديم ومتكرر وطبقة المتغيرات `--ui-*`.
- إزالة أيقونة الدور النصية `↔` من CSS.
- استبدال رمز السحب النصي في `app.js` بأيقونة SVG.
- تنظيف مراجع الأجيال السابقة (`design47`, `d42-*`, `d44-*`, `d48-*`, `v47-*`, `ui-inline-icon-*`).
- الإبقاء على الكلاسات الدلالية اللازمة للـ JavaScript والـ DOM، مع اعتماد مكوّنات `ds-*` كأساس للغة البصرية.

- Python compile: ناجح.
- CSS parser: بلا أخطاء.
- لا توجد مراجع للأجيال القديمة في `templates` أو `static`.
- لا توجد الرموز النصية التي كانت مستخدمة كأيقونات في `templates` أو `static`.

### v49.25 — إصلاح UndefinedError في صفحة الإدارة

## الإصلاح
تم إصلاح خطأ Jinja التالي الذي كان يمنع فتح «الإدارة»:

`jinja2.exceptions.UndefinedError: 'actual_roles' is undefined`

السبب أن `actual_roles()` موجودة في `app.py` وتستخدم داخل القوالب، لكنها لم تكن مسجلة ضمن globals الخاصة بـ Jinja.

تم تسجيلها صراحةً:

`app.jinja_env.globals['actual_roles'] = actual_roles`

## التحقق
- Python compileall: ناجح.
- فحص Jinja لجميع القوالب: ناجح (35 قالبًا).
- استيراد التطبيق: ناجح.
- التحقق من تسجيل `actual_roles` في Jinja: ناجح.

## ملاحظة
لم يتم تغيير منطق الأدوار أو بيانات النظام؛ الإصلاح خاص بإتاحة الدالة للقالب.

# v47 — مراجعة شاملة للواجهة وتجربة الاستخدام

تمت مراجعة طبقة الواجهة وقوالب التطبيق بالكامل، مع التركيز على RTL والعرض العربي الموحد.

## ما تم توحيده
- نظام تصميم واحد `design49.css` فقط.
- Header / Sidebar / Role Switcher / Scope.
- البحث العالمي عن الموظفين من مكان واحد.
- البطاقات والنماذج والحقول والجداول والأزرار والحالات.
- صفحات الموظفين والحركات والتقارير والمأموريات والإدارة والتفويض.
- إزالة أنماط CSS القديمة من الحزمة.
- إزالة inline styles من القوالب وتحويلها إلى utilities داخل Design System.
- إزالة الرموز التعبيرية من واجهة القوالب واستبدالها بعناصر أيقونات موحدة.

## قواعد UX المعتمدة
- البحث العالمي عن الموظف يعمل عبر جميع المحافظات، مستقل عن نطاق التشغيل.
- اختيار نطاق التشغيل لا يبدأ بحثًا أو عرضًا تلقائيًا للموظفين.
- «حالة الموظفين الآن» تعرض الموظفين الذين لديهم حركة فعلية فقط.
- المشرف يرى عبارة واضحة عن عدد المحافظات المسندة إليه، لا عبارة «كل النطاقات».
- تغيير الدور ظاهر باسم «تغيير الدور» ويعيد ضبط سياق التشغيل.
- لا يوجد بحث موظفين ثانٍ في الصفحة الرئيسية.
- إجراءات سريعة تظهر مرة واحدة في ست بطاقات موحدة.
- إدارة المدخل الأول تتضمن تعديل الفروع، الاستبدال، وإزالة الدور التنظيمي.
- المساعد الذكي يستخدم نافذة واحدة مشتركة بين الزر العائم وزر Sidebar.

# v49.17 — المراجعة الشاملة النهائية للتصميم

## نطاق المراجعة
تمت مراجعة طبقة الواجهة كاملة: App Shell، الرئيسية، الموظفون، ملف الموظف، الحركات، التقارير والمأموريات، الإدارة، حسابي، تسجيل الدخول، والمساعد الذكي.

## ما تم إصلاحه في هذه المرحلة
- إزالة تكرارات واضحة في قواعد App Shell عند نقاط الاستجابة.
- إبقاء قواعد السلوك الخاصة بالقائمة الجانبية المصغرة على الهاتف مع الطبقة الموحدة.
- إزالة تعريف utility مكرر لـ `ds-inline`.
- استبدال أيقونات نصية متبقية في المساعد الذكي بـ SVG.
- استبدال أيقونات المساعد الديناميكية التي كانت Emoji/Unicode بمفاتيح دلالية تُرسم كـ SVG.
- استبدال سهم الإرسال وسهم إجراءات المساعد وأيقونة الإغلاق النصية بـ SVG.
- استبدال رموز الرجوع النصية في الشاشات التشغيلية بأيقونات SVG.
- عدم تغيير منطق الصلاحيات أو نطاق المحافظة أو منطق الحركات.

## ما بقي عمدًا
الكلاسات الدلالية الخاصة بالصفحات التي تستخدمها JavaScript أو النماذج لم تُحذف لمجرد تغيير الاسم؛ وجودها كـ hooks لا يعني أنها Design System مستقل.

## التحقق
- Jinja templates: 35 — بدون أخطاء parsing.
- Python compile: ناجح.
- CSS parser: بدون أخطاء.
- CSS braces: متطابقة.
- مراجع الأجيال القديمة في ملفات التطبيق: لا توجد.

## ملاحظة
النسخة لا تدّعي أن كل اسم CSS غير `ds-*` قد اختفى؛ بعض الأسماء الدلالية ما زالت مطلوبة للسلوك والربط البرمجي. المعيار هنا هو عدم وجود طبقة تصميم قديمة مستقلة أو override تاريخي منفصل.

v35.17 — توحيد التطبيع العربي في اكتشاف موضوع الرسالة

تم توسيع التطبيع ليُستخدم قبل اكتشاف موضوع الرسالة نفسه، وليس فقط عند البحث عن الموظفين والفروع.

أمثلة مدعومة:
- إجازة / اجازة / اجازه / إجازه / الاجازه -> موضوع الإجازة
- انتداب / إنتداب / مأمورية -> موضوع الانتداب
- إذن / اذن -> موضوع الإذن
- منى / مني، هدى / هدي -> مطابقة بحث الأسماء

القيمة الأصلية في قاعدة البيانات لا تتغير.
